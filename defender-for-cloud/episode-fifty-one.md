# Defender for Open-Source Relational Databases multicloud - Microsoft Defender for Cloud | Microsoft Learn

**Episode description**: In this episode of Defender for Cloud in the Field, Catalin Esanu joins Yuri Diogenes to talk about Defender for Open-Source Relational Databases. Catalin shares updates about Defender for Databases, and then he talks about the new AWS and GCP scenario for databases. Catalin also demonstrates how Defender for Cloud detects alerts with threat protection for Open-Source Relational Databases.

- [02:13](/en-us/shows/mdc-in-the-field/open-source-relational-databases-multicloud#time=02m13s) - Understanding the new additions for database protection in multicloud environments.
- [05:52](/en-us/shows/mdc-in-the-field/open-source-relational-databases-multicloud#time=05m52s) - Amazon Relational Database Service (RDS) protection, which is now generally available.
- [07:00](/en-us/shows/mdc-in-the-field/open-source-relational-databases-multicloud#time=07m00s) - Threat detection alerts for databases in multicloud environment.
- [08:53](/en-us/shows/mdc-in-the-field/open-source-relational-databases-multicloud#time=08m53s) - Demonstration
