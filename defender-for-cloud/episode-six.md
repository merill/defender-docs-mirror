# Lessons learned from the field - Microsoft Defender for Cloud | Microsoft Learn

**Episode description**: In this episode, Carlos Faria, Microsoft Cybersecurity Consultant, joins Yuri to talk about lessons from the field and how customers use Microsoft Defender for Cloud to improve their security posture and protect their workloads in a multicloud environment.

Carlos also covers how Microsoft Defender for Cloud fills the gap between cloud security posture management and cloud workload protection platform (CWPP), and demonstrates some features related to this scenario.

- [1:30](/en-us/shows/mdc-in-the-field/lessons-from-the-field#time=01m30s) - Why Microsoft Defender for Cloud is a unique solution when compared with other competitors?
- [2:58](/en-us/shows/mdc-in-the-field/lessons-from-the-field#time=02m58s) - How to fulfill the gap between CSPM and CWPP
- [4:42](/en-us/shows/mdc-in-the-field/lessons-from-the-field#time=04m42s) - How a multicloud affects the CSPM lifecycle and how Defender for Cloud fits in?
- [8:05](/en-us/shows/mdc-in-the-field/lessons-from-the-field#time=08m05s) - Demonstration
- [12:34](/en-us/shows/mdc-in-the-field/lessons-from-the-field#time=12m34s) - Final considerations
