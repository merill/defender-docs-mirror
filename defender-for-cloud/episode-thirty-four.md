# Understanding the DevOps Threat Matrix - Microsoft Defender for Cloud | Microsoft Learn

**Episode description**: In this episode of Defender for Cloud in the Field, Ariel Brukman joins Yuri Diogenes to talk about the DevOps Threat Matrix. Ariel talks about the process of creating a new threat matrix for a very complex domain such as DevOps, what he found during the research process, and how the research evolved to create this threat matrix. Ariel also talks about how to use the threat matrix to improve your DevOps defenses, and gives examples of some common attacks against DevOps environments.

- [02:49](/en-us/shows/mdc-in-the-field/devops-threat-matrix#time=02m49s) - The research leading to DevOps Matrix publication
- [05:35](/en-us/shows/mdc-in-the-field/devops-threat-matrix#time=05m35s) - Threats in the execution phase
- [08:50](/en-us/shows/mdc-in-the-field/devops-threat-matrix#time=08m50s) - Privilege escalation phase
- [13:00](/en-us/shows/mdc-in-the-field/devops-threat-matrix#time=13m00s) - Common patterns of attack
- [13:42](/en-us/shows/mdc-in-the-field/devops-threat-matrix#time=13m42s) - Recommendations to build better defenses
