# Review agentic code scan results in the Microsoft Defender portal - Microsoft Security Exposure Management | Microsoft Learn

Agentic code scan findings are surfaced in the Microsoft Defender portal through Microsoft Security Exposure Management (MSEM). The Codename MDASH - Agentic code scanner initiative aggregates findings for all scanned repositories, giving security teams a centralized view for vulnerability tracking and remediation.

## Understand the initiative dashboard

For detailed guidance on navigating the initiative dashboard, working with metrics, and managing findings, see [Codename MDASH - Agentic code scanner initiative](mdash-initiative).
