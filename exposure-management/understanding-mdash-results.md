# Review agentic code scan results - Microsoft Security Exposure Management | Microsoft Learn

After running an agentic code scan, you can review findings in two places: directly from the terminal using the Defender CLI output files, or in the Microsoft Defender portal through Microsoft Security Exposure Management.

## Review options

| Where | Best for |
| --- | --- |
| [Terminal results](review-terminal-results) | Reviewing individual scan output — HTML reports and SARIF files generated by the CLI. |
| [Microsoft Defender portal](review-portal-results) | Organization-wide view — aggregated findings, triage, and remediation tracking for all scanned repositories. |
