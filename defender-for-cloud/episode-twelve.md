# Enhanced workload protection features in Defender for Servers - Microsoft Defender for Cloud | Microsoft Learn

**Episode description**: In this episode of Defender for Cloud in the Field, Netta Norman joins Yuri Diogenes to discuss the enhanced capabilities of Defender for Servers. They explore how it protects VMs in Amazon Web Service (AWS), Google Cloud Platform (GCP), and on-premises environments.

Netta explains how Defender for Servers applies Azure Arc as a bridge to onboard non-Azure VMs and demonstrates what the experience looks like.

- [00:55](/en-us/shows/mdc-in-the-field/enhanced-workload-protection#time=00m55s) - Arc autoprovisioning in GCP
- [2:57](/en-us/shows/mdc-in-the-field/enhanced-workload-protection#time=02m57s) - Prerequisites to Arc autoprovisioning
- [3:50](/en-us/shows/mdc-in-the-field/enhanced-workload-protection#time=03m50s) - Considerations when enabling Defender for Server plan in GCP
- [5:20](/en-us/shows/mdc-in-the-field/enhanced-workload-protection#time=05m20s) - Dashboards refresh time interval
- [7:00](/en-us/shows/mdc-in-the-field/enhanced-workload-protection#time=07m00s) - Security value for non-Azure workloads
- [9:06](/en-us/shows/mdc-in-the-field/enhanced-workload-protection#time=05m20s) - Demonstration
